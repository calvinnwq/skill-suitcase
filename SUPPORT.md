# Support

Skill Suitcase is maintained as an open source project. Support is best effort;
there is no guaranteed response time or private support channel for general
usage questions.

## Start With The Documentation

- [`README.md`](README.md) describes commands, output, and safety boundaries.
- [`INSTALL.md`](INSTALL.md) covers installation and operator setup.
- [`docs/install-smoke.md`](docs/install-smoke.md) provides smoke checks.
- [`docs/portability-matrix.md`](docs/portability-matrix.md) explains target and
  variant portability.

## Ask For Help Or Report A Problem

Use this repository's issue chooser:

- choose **Bug report** for reproducible incorrect behavior
- choose **Feature request** for a proposed capability or workflow change
- choose **Support question** when the documentation does not answer a usage or
  setup question

Before filing, check existing issues and retry with the newest release when
practical. Include the released version or commit, operating system, Node.js
version, the exact command shape, relevant deterministic JSON output, and a
minimal reproduction. Redact credentials, personal paths, private catalog
content, and agent state.

Suspected vulnerabilities must be reported privately through
[`SECURITY.md`](SECURITY.md), not through the public issue tracker.

## Support Boundary

The project can help with Skill Suitcase's documented CLI behavior. Runtime
setup for third-party agents, content authored by third-party skills, GitHub or
npm service availability, and unsupported local modifications may need to be
handled by their respective maintainers. A minimal reproduction that isolates
Skill Suitcase behavior makes that boundary easier to determine.
